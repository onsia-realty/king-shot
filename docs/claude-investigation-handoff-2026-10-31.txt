킹샷공략 지도·검색 복구 — Claude 조사 결과 인수인계 (2026-10-31)

대상: GPT 세션. 아래는 Claude가 2026-10-29~30에 직접 확인한 사실과, 그에 따라 작성한 코드의 상태다.
추정은 "추정"이라고 표시했다. 키·토큰·DB 주소는 이 문서에 없다.

1. 차단 원인 (확정)
- 사이트의 /api/map, /api/search 는 MightPulse 웹사이트 내부 주소
  (mightpulse.com/api/map?kid=..., /api/search?q=...)를 Vercel 함수가 대신 불렀다.
- 같은 주소를 개인 PC에서 부르면 200 JSON, Vercel 함수에서 부르면 Cloudflare 챌린지(403) → 사이트는 502.
  키 문제 아님(해당 주소는 키를 쓰지 않음), 주소 변경 아님(웹 프론트가 지금도 같은 주소를 씀).
- 결론: MightPulse가 클라우드 IP·비브라우저 요청을 의도적으로 막았다. 챌린지 우회는 하지 않는다.

2. MightPulse 공식 API (실제 호출로 확정)
- 기본 URL https://api.mightpulse.com/v1, 헤더 Authorization: Bearer kss_... (env MIGHTPULSE_API_KEY).
- 엔드포인트 10개뿐: /usage, /players/{id}, /alliances/{kid}/{tag}, /kingdoms, /kingdoms/{kid},
  /kingdoms/{kid}/ranks, (Mighty 전용) /kingdoms/{kid}/events, /kvk, /kvk/scores, /kvk/matchups.
- 지도·구역·좌표 조회·닉네임 검색 엔드포인트는 없다.
- 좌표(x, y)는 /players/{uid}?id_type=uid 응답의 player 객체에만 있다 → 플레이어 1명당 1콜.
- /alliances/{kid}/{abbr}?include=roster → members[]: uid, governor_id, fid, nick_name, power,
  town_center_level, kills, alliance_rank, kid, avatar_url. 좌표 없음. abbr는 대소문자 구분.
- /kingdoms/{kid}/ranks?board=alliance_power&limit=100 → board.rows[]: rank, aid, abbr, name, score, member_count...
  board 슬러그 26종(personal_power, kills, town_center 등). 개인 보드 rows에도 좌표 없음.
- /kingdoms/1622 → player_count 4542, located 1332, alliance_count 590.
  → MightPulse 웹 지도(1,332개)는 "위치를 파악한 플레이어"만 그린 부분 지도다.
- 한도: 무료 분당 60·일 5,000 / Mighty 분당 120·일 10,000. 신선도 최대 60분, 오래된 구역은 최대 90초 대기.
- Cloudflare가 기본 라이브러리 User-Agent(python-urllib 등)를 403 "error code: 1010"으로 거부한다.
  User-Agent: kingshot-gongryak-site/1.0 (+https://xn--ob0bx7rdoh9mq.xyz) + Accept: application/json 은 통과 확인.
  Vercel의 Node fetch(undici UA)도 /players 에서는 통과했다는 보고가 있으나, 명시 UA를 권장.
- 검증 예: Dorian uid 56244698 / governor_id 223733988 / x436 y653 / 연맹 ROK(aid 163100207).
  governor_id(게임 프로필의 9자리 "ID")와 uid(내부 8자리)는 다른 값이다. 둘 다 API가 받는다.

3. 게임 클라이언트 통신 (확정, 채택 안 함)
- APK com.run.tower.defense 1.14.19 (Unity IL2CPP + Lua). 게임 소켓 184.85.235.241:30101 (TCP, TLS 아님).
  34.217.151.18:13321 은 채팅(FPNN), 지도와 무관.
- 서버→클라이언트 프레임: 2바이트 빅엔디안 길이 + Skynet sproto 0-pack 본문(8바이트마다 비트맵 1바이트, 0바이트 생략, 0xFF=원본 묶음).
  암호화 아님. 풀면 도시 레코드가 x, y(sproto small int) … uid(u32le), 이름, aid(u32le), 연맹약자 순으로 나온다.
- 도시 2곳(Dorian, 말랑말랑)의 uid·x·y·연맹이 게임 화면 및 MightPulse 스냅샷과 정확히 일치. 4회 재로딩에서 동일.
- 클라이언트→서버 요청(62바이트)은 마스킹돼 있고 클라이언트에 보호 라이브러리(libNetHTProtect/libnesec)가 있다.
  로그인·요청 재현 = 가짜 클라이언트 = 봇 우회·제재 위험 → 하지 않는다.
- 에뮬레이터(BlueStacks) 순회 + 응답 읽기 방식은 기술적으로 가능하나 사용자가 보류(수작업 성격, 왕국당 수 분 추정).
- 캡처 도구: BlueStacks 루트 없음 → Windows pktmon(관리자)으로 호스트에서 캡처. 스크립트는 Claude 스크래치에만 있음.

4. 공식 기프트코드 사이트 (미확정, 보류)
- ks-giftcode.centurygame.com 프론트 코드상 API 베이스 https://kingshot-giftcode.centurygame.com/api, 경로 /player, /gift_code, /captcha.
  MD5 서명 사용. 실제 호출은 404(폼·JSON 둘 다) → 요청 형식 또는 서명 조합이 다름. 어차피 좌표가 없어 지도에 쓸모없음.

5. 결론과 설계 (사용자가 "장기 방식"으로 채택, 당장은 GPT 연맹 지도 유지)
- 유일하게 지속 가능한 데이터 원천은 공식 API. 좌표가 플레이어당 1콜이므로 "그때그때 호출"이 아니라
  "미리 모아서 저장"해야 모든 방문자에게 한도 걱정 없이 지도·검색을 줄 수 있다.
- 구조: 공식 API → GitHub Actions 수집기(매시 15분, 1회 180콜 ≈ 하루 4,300콜) → Neon DB → 사이트 API.
  방문자가 없는 왕국을 열면 kingdom_requests 큐에 등록, 수집기가 선입선출로 처리.
  왕국 1개 첫 수집 ≈ 명단 100콜 + 좌표 1,300콜 ≈ 8회. 검색은 첫 실행 직후부터, 지도는 좌표 차는 대로.
- 저장소에 작성된 파일(커밋 안 됨):
  migrations/002_kingdoms.sql            kingdom_requests / alliances / players 테이블
  scripts/collect-kingdoms.mjs           수집기 (--probe: /usage만, DB 불필요)
  .github/workflows/collect-kingdoms.yml 매시간 실행, secrets MIGHTPULSE_API_KEY·DATABASE_URL
  src/lib/server/kingdom-store.ts        DB 읽기 공용
  api/map.ts, api/search.ts, api/map-refresh.ts  DB 기반으로 재작성 (응답 형식은 기존 화면과 호환)
  api/player.ts                          공식 API 호출에 UA·Accept 헤더 추가
  README.md "왕국 데이터 수집" 절
- 검증: node --test "tests/*.test.mjs" 108 통과, npm run check 오류 0 (GPT 연맹 지도 파일 포함한 트리 기준).
  실제 DB 실행은 미검증(Claude 환경에서 DB 주소 취득이 차단됨).
- 켜기 위해 남은 일: ① Neon에서 002 실행 ② GitHub Secrets 2개 ③ Vercel 프로덕션에 새 MIGHTPULSE_API_KEY ④ 워크플로 kids=1622 수동 실행.

6. GPT 작업과의 관계
- GPT의 api/alliance-map.ts + OfficialAllianceMap.tsx(공식 API 실시간, 연맹 단위, 프로세스 캐시)는 그대로 둔다.
  KingdomMap.tsx 가 그것으로 교체돼 있어 현재 DB 기반 /api/map 은 화면에서 호출되지 않는다. /api/search 는 PlayerDiscovery가 계속 쓴다.
- 두 방식은 공존 가능: "이 연맹만 지금 바로" = 연맹 지도, "왕국 전체 지도·닉네임 검색" = DB.
  원래 캔버스 지도를 되살리려면 git show HEAD:src/components/islands/KingdomMap.tsx 를 복원해 /api/map/?kid= 에 연결하면 된다.
- 같은 API 키를 두 경로가 쓰므로 하루 5,000콜을 나눠 써야 한다. 연맹 지도 쪽 분당 40콜 상한 + 수집기 분당 54콜은 동시에 돌면 60을 넘을 수 있다.
  수집기는 429를 받으면 다음 분까지 대기하도록 돼 있으니 깨지지는 않지만, Mighty(분당 120)면 여유가 생긴다.

7. 하지 않을 것 (사용자 제약 + Claude 판단)
- Cloudflare 챌린지 우회, 브라우저 위장 UA, 프록시 회전.
- 게임 클라이언트 로그인·요청 마스킹 재현(가짜 클라이언트).
- 개인 PC·에뮬레이터에서만 동작하는 결과.
